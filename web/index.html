JSON format

A tree needs a name and optional topics. Each topic has a name, level (0 gap, 1 theory, 2 practising, 3 learnt), and optional nested children. Set suggested: true for a suggested gap. IDs are generated for you.

Workspace exports contain {"version":1,"trees":[...]}. Import adds copies; existing trees stay in place. Up to 30 trees, 1,000 topics, 12 levels, and 1 MB per import.
